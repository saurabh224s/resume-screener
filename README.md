# HireIQ — AI Resume Screener

AI-assisted resume screening against a job description.

## Privacy and security

Resumes contain sensitive personal information. Use synthetic or consented test data when possible. Never commit uploaded resumes or credentials, and never put real candidate data in public issues or pull requests.

AI-generated scores and recommendations should be reviewed by a human and should not be the sole basis for an employment decision.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```
